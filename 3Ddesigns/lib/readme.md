

# Origin of External Components used

This directory contains three external STL models used in the enclosure design:

1. **GMT020-02 TFT SPI LCD**
	- Source: [GrabCAD](https://grabcad.com/library/gmt020-02-ver1-1-2-0tftspi-lcd-1)
	- 3D model of the display used in this project.

2. **Garmin Quarter Turn Mount**
	- Source: [Thingiverse](https://www.thingiverse.com/thing:2666998)
	- Garmin-style mount, included in the GPS module base for secure attachment.

3. **Quadlock Socket Receiver**
	- Source: [Printables](https://www.printables.com/model/134144-quadlock-socket-reciever/files)
	- Adapter for Quadlock mounting system, used in the bottom cover version to attach the case to a Quadlock adapter.
